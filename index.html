🔧 Cách cài đặt Skill vào Claude

Cài đặt qua giao diện Claude (Khuyến nghị)

1

Tải file .skill

Mỗi skill là 1 file .skill. Chọn skill bạn muốn cài — ví dụ okr-va-kpi.skill và lưu về máy.

2

Mở Customize

Trên giao diện Claude, bấm vào tên tài khoản hoặc biểu tượng cài đặt, chọn Customize.

3

Vào mục Skills

Trong trang Customize, chọn tab Skills để xem danh sách skill đã cài và tuỳ chọn thêm mới.

4

Bấm Add Skill

Bấm nút "Add Skill", sau đó chọn file .skill vừa tải về để upload lên.

5

Skill sẵn sàng!

Skill xuất hiện trong danh sách. Từ lần sau chỉ cần nhắn tin theo chủ đề — Claude tự nhận biết và kích hoạt skill đúng.

💬 Cách sử dụng Skills

Không cần gõ lệnh — Chỉ cần nói điều bạn muốn làm

✅ Kích hoạt tự động

Claude nhận diện yêu cầu và tự động gọi skill phù hợp. Bạn không cần nhớ tên skill.

"Giúp tôi viết JD tuyển dụng Marketing Manager"
📊 Dùng template có sẵn

Mỗi skill có biểu mẫu, quy trình, checklist sẵn — chỉ cần yêu cầu điền thông tin cụ thể.

"Lập kế hoạch OKR quý 3 cho phòng Sales"
🔗 Kết hợp nhiều skill

Skills bổ trợ nhau. Dùng skill phân tích tài chính rồi xuất ra Excel với skill xlsx.

"Phân tích DuPont ROE rồi tạo file Excel dashboard"
📝 Tạo file đầu ra

Claude có thể xuất kết quả thành file .docx, .xlsx, .pptx, .pdf tùy yêu cầu.

"Soạn hợp đồng lao động và lưu thành file Word"
